# COVID-19 Global Data Analysis

Exploratory data analysis of the Johns Hopkins COVID-19 dataset (Jan 2020 – Mar 2023).

# What this project covers:
- Cumulative case trends across India, US, and UK
- Daily new cases with 7-day rolling average
- Top 10 countries by total cases
- Death rate over time
- India cases vs deaths comparison
- Monthly heatmap across countries

# Tools used
Python, Pandas, Matplotlib, Seaborn

# Dataset
Johns Hopkins CSSE COVID-19 Time Series — loaded directly from GitHub

# Key findings
- The US Omicron wave in January 2022 produced the highest single-month case count globally
- India's Delta wave in May 2021 was its deadliest period despite not being its highest case wave
- Death rates dropped below 1% across all countries by 2022 as vaccination scaled up
